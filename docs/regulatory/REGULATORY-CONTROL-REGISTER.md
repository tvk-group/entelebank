# EnteleBANK Regulatory Control Register

## Purpose
Prevent public, technical and regulatory artefacts from drifting away from the factual status of the prospective institution.

| Control | Current rule | Evidence / owner |
|---|---|---|
| Sensitive name | ENTELEBANK LTD remains subject to FCA sensitive-name assessment | Issue #9 / regulatory record |
| Regulatory status | Never describe EnteleBANK as authorised, licensed or regulated as a bank before authorisation | Website footer + regulatory page |
| Deposits | No deposit acceptance before relevant permission | RBP / public terms |
| FSCS/FOS | No protection/access claims unless legally applicable | Regulatory page |
| Product availability | All banking products remain proposed until permitted and operational | Product pages |
| FCA/PRA relationship | No endorsement/approval implication | All public communications |
| Application references | Administrative references are not public regulatory credentials | Internal records only |
| Launch date | No promised authorisation or launch date | Roadmap |
| Translations | English regulatory text authoritative until controlled translation approval | i18n catalogue |
| Change control | Material proposition/status changes require cross-document review | This register |

## Release review
Before any public-facing merge, verify:
1. Does the change imply EnteleBANK already operates as a bank?
2. Does it imply PRA/FCA approval, authorisation or endorsement?
3. Does it imply FSCS/FOS protection?
4. Does it make a proposed service appear available now?
5. Does it contradict the Sensitive Business Name submission or current RBP?
6. Does it create a new regulated activity, target market or material group dependency that requires regulatory/perimeter review?

If any answer is yes or uncertain, hold the public release for regulatory review.
